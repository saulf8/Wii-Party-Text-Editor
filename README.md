<b><u><span class="RedColor">Wii Party Text Editor</span></u> </b>is a text editor for the mess.bin files in Wii Party. It features a live preview and full support for all regions. There are currently builds for Windows and Linux (Ubuntu). In addition, a python script is also provided that converts mess.bin files into XML and vice-versa. It has some similarities to Party Espionage, but it is not related in any way (code or otherwise).<br><hr><h1><span class="RedColor"><u>Format Details</u></span></h1>You may see the format referred to as "XMSG" in some areas. This is because of the file magic. There is no official name for the file format. <br><br><h2>Tags</h2>Wii Party supports two tags, [c:] and [r:]. For the c tag, an RGBA color needs to be provided like so:<br>[c:#rrggbbaa]text. Now the following text will all have the color specified by the c tag, rather than the color specified by the message style.<br><br>The r tag is for ruby text, which are small annotations above the text. It can be used like so: [r:text to go above]Text that is below[/r]. <br><br><h2>Placeholders</h2>There are also certain sequences that are replaced by the game. Placeholders such as \[0\] and \[1\] will not change to anything if added to a new message, but if they are in existing messages they can update to a new value (ex: a high score). There are placeholders for button images, which are all supported.<br><ol><li><span class="GreenColor"> \[ba\] </span>- A button</li><li> <span class="GreenColor">\[bb\]</span> - B button</li><li><span class="GreenColor">\[b1\]</span> - 1 button</li><li> <span class="GreenColor">\[b2\]</span> - 2 button</li><li> <span class="GreenColor">\[bx\]</span> - D-Pad</li></ol><hr><h1><span class="RedColor"><u>Features</u></span></h1><h2>Message Sorting</h2>Messages are sorted by type and organized in a tree structure. In addition, they are also separated among different game types.<br><br><h2>Search (CTRL + F)</h2>Messages can be searched for either by name, type, or contents. <code>style:id </code>can also be added to any search query or searched independently to also only match messages that have a specific style id (0, 1, 2, etc.).<br><br><h2>Reveal Selection (CTRL + G)</h2>Reveal Selection will scroll the message list to focus on your selected message. This is useful if you were searching for another message and lost your place.<br><br><h2>Style Editing</h2>The message styles and specific style that a message uses can be edited. These styles dictate the text color, text stroke color, text width and height, text spacing, and Party Phil's expressions (if he is visible).<br><br><h2>Easy Reversion</h2>The original text from when the file was loaded is displayed alongside the edited text so that changes can easily be rolled back. In addition, every other field related to the messages have a revert button next to them that will also restore to the original.<br><br><h2>Game View</h2>Messages are displayed at the bottom of the screen in a similar manner to how they are in game, allowing wrapping to be fixed ahead of time.  Wrapping must be done manually as Wii Party wraps by the letter, not by the word. Different text box sizes can be set to accurately preview text in different areas. <br><ol><li> <b>Wide</b>: used for when Party Phil is talking, but he isn't visible.</li><li> <b>Narrow</b>: used for when Party Phil is talking, and he is visible.</li><li> <b>Game Guide</b>: used for minigame explanations and game explanations in the menu.</li><li> <b>FC Question</b>: used for questions in Friend Connection.</li><li> <b>One-line</b>: used for areas where text is displayed on one line. For example, Friend Connection answers and word bomb themes.</li><li> <b>System: </b>used for alerts by the system, such as a Wiimote disconnecting or a new Mii being registered.<br></li><li> <b>Custom</b>: a custom textbox width and height can also be set.</li></ol>The sizes may not be 100% accurate as the game view is just an approximation, not a 1:1 recreation. If there are any issues with wrapping in particular, please report it. The font is different from the one in Wii Party and will display symbols such as emojis, but these will not be visible in game without first editing the font.<br><br><h2>XML Export</h2>The mess.bin can also be saved as an xml, which can both be read by the editor and edited in any external text editor. Please be careful editing the xml, as improper editing will make the xml invalid. The xml cannot be read by the game, but it can be converted back into an xml using the editor.<br><hr><h1><u><span class="RedColor">Tips</span></u></h1><h2>Friend Connection /  Buddy Quiz Questions</h2>For editing Friend Connection and Buddy Quiz questions, it is highly recommended to export the file as an xml and edit it externally. The questions and answers will be shown sequentially. Some questions have only two possible answers, and some have six, where four are chosen at random.<br><br><h2>Mii Names</h2>A search for "mii" or "mii_name" will allow the mii names to be accessed and edited easily. Mii names should be kept 10 characters or under, so that they display properly.<br><br><h2>Changing Styles</h2>Changing the data of a style is simple, but it will also affect all other messages that use that same style. It is recommended to either change the style index a message uses to one that is preferable, us e a [c] tag to change the color of the text, or find a style that is unused or is used by unused text by searching with <span class="GreenColor">style:id </span>(ex: <span class="GreenColor">style:0</span>).<br><br><h2>Searching</h2>When searching, some results you expect may not appear because the visible text is different from the raw text. Searching for small portions of a message that are the same color is preferable.<br><hr>
